#    connectedComponents 채널 assertion이 바뀌어 detection/craft_detector.py가 깨진다.
#    4.11.0.86은 cp37-abi3 휠이라 py3.14에서도 설치된다.
# 2. craft-text-detector 0.4.3은 여기 목록에서 뺐다 — 이 패키지가 잘못된 핀

#    빌드를 시도하다 실패하기 때문. 반드시 `--no-deps`로 따로 설치한다.
#    설치 후에는 torchvision 0.28에서 제거된 `models.vgg.model_urls` import 때문에 로드가
#    안 되므로 아래 파일을 1줄 패치한다 (CraftNet은 생성 직후 craft_mlt_25k.pth 전체
#    가중치로 덮어써지므로 VGG 백본 ImageNet 사전학습은 불필요):
#      venv/lib/python3.*/site-packages/craft_text_detector/models/basenet/vgg16_bn.py
#        - `from torchvision.models.vgg import model_urls`   ← 삭제
#        - `models.vgg16_bn(pretrained=pretrained)`          → `models.vgg16_bn(weights=None)`
#        - `model_urls["vgg16_bn"] = ...` 재할당 줄           ← 삭제
