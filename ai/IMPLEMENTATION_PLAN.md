## 0. 확정 전제 (설계 기준선)

- **이미지 모드 = 자유 촬영**. OCR/텍스트 인식 없음, 목표 텍스트 모름 →
  **자기 일관성(상대) + 절대 규범(별도 축)** 만 평가.
- **캔버스 모드 = 제시형**. 표준체(명조=기하 기준점) 대비 획순·자간·크기.
- 두 모드 **동등 주력**.
- 피드백 = **룰 기반 템플릿, 문서 단위**(개별 글자 지적 없음).

## 1. 지금 구현 — 이미지 모드 (`analysis/handwriting_analyzer.py`, `AI_MODEL_INTERFACE.md §4`)

### 1.1 [P0] 종합점수 구조 개편 — 단순평균 → 지표별 점수 + 교육적 가중 종합
- **현재**: `total_score` = score가 있는 지표들의 **단순 산술평균**(가중치 없음).
- **변경**:
  - 지표별 개별 점수(`metrics[].score`)는 그대로 노출(이미 존재).
  - 종합점수 = **가중 평균**. 가중치(정렬·균일 우선, **3:2:1**):
    | 지표 | 가중치 |
    |---|---|
    | `height_uniformity` (크기 균일) | 3 |
    | `baseline_deviation` (기준선) | 3 |
    | `line_spacing_uniformity` (행간) | 3 |
    | `tilt_consistency` (기울기 일관) | 2 |
    | `spacing_uniformity` (자간) | 2 |
    | `clarity` (명료도) | **제외** (1.2 참고) |

    > **정정 2026-07-27 (T4)**: `stroke_width_uniformity`(획 굵기, 가중치 1) 지표를 **제거** —
    > 이미지 모드는 위 **5지표 체계**. 정렬·균일 우선 3:2:1 가중치는 유지.
  - `total_score = Σ(scoreᵢ·wᵢ) / Σ(wᵢ)`, `skipped` 지표는 분자·분모 모두 제외.
  - 가중치는 **모듈 상수 dict**로 노출(REQ-005I-5 "설정 파일로 조정 가능" 취지). 3:2:1은
    초기값이며 실사용 데이터로 튜닝.
  - 종합점수에도 등급(우수/보통/불량) 매핑 추가(현재 total엔 등급 없음).
- **검증**: `debug_analysis.py`로 test 4장 종합점수 재계산, 기존 대비 변화 확인.

### 1.2 [P0] 명료도(clarity) → 경고 전용, 점수 미반영
- **현재**: `clarity`가 `metrics`에 score로 들어가 `total_score`에 반영됨.
- **변경**: `clarity` score를 종합점수 계산에서 **제외**하고, `clarity_warnings`(경고 리스트)로만
  반환. 근거: 탐지 실패를 사용자 필체 탓으로 돌릴 위험(모델 한계 ≠ 못 쓴 글씨).
- **유지**: `chars[].clarity_flag`(merged_suspect/tilt_outlier/low_confidence)는 **다른 지표
  통계 오염 방지 게이트로 계속 사용**. 단지 "점수"로만 안 씀.

### 1.3 [P1] 절대 규범 축 신설 — 자기 일관성과 별개 축
> "고르게 썼어도 일반적인 글의 형식을 벗어나면 감점". 자기 일관성 점수와 **별도 축으로 병렬**
> 표시. 대상 = **자간·기울기·행간** (글자 크기는 제외).
- **출력**: `analyze_size_angle` 반환에 `norm_deviations` 신설
  (예: `{tilt: {violated, value, message}, spacing: {...}, line_spacing: {...}}`).
  종합점수(1.1)와 **분리**된 축.
- **① 기울기 규범 — 수직(0°) 기준 이탈**
  - `mean_angle`(신뢰 글자 slant 평균, 이미 계산됨)의 절대값이 임계 초과 시 경고.
  - ⚠️ 현재 코드 전제("개인 습관 slant는 일정 → 이상치 버리고 σ만 봄")와 **충돌**.
    일관성(σ) 축은 그대로 두고, **절대 방향(|mean_angle|)** 을 별도 규범 축으로 추가.
  - 신뢰 글자 3자 미만이면 생략(기존 `TILT_MIN_RELIABLE` 규칙 재사용).
  - 임계값(초안, **문헌 검증 대상 → 3.3**): |mean_angle| > `TILT_NORM_DEG` (예: 7~10°).
- **② 자간 규범 — 띄어쓰기(단어 경계) 뭉개짐: 자간 분포 이봉성으로 감지**
  - 원리: 같은 줄 인접 글자 pitch가 정상적으로 **"글자 사이(좁음) / 단어 사이(넓음)"
    두 군집(bimodal)**. 넓은 군집이 (거의) 사라지면 = 전부 붙여 씀 = **띄어쓰기 실종** 경고.
  - 구현: 기존 `WORD_GAP_RATIO`(행높이×0.55) 로직 재활용 — 지금은 큰 gap을 자간 CV에서
    "띄어쓰기"로 제외 중. 이 **제외되는 큰 gap 표본이 0에 수렴**하면(그리고 글자·줄 수가
    충분하면) 규범 위반 후보로 판정. (또는 줄별 gap에 1D 2-군집 분리.)
  - 오탐 방지 게이트: 최소 글자 수 / 최소 줄 수(짧은 단어 한 개 촬영은 제외).
- **③ 행간 규범 — 줄이 겹치게 붙음**
  - baseline 간격 절대값 / 평균 글자 높이 < `LINE_NORM_MIN_RATIO`(초안 예: 1.0) → 경고.
  - 3행 이상만(기존 `LINESPACE_MIN_ROWS` 재사용).
- **표시**: 규범 이탈은 **점수를 깎지 않고**, "글씨가 전체적으로 8° 기울어 곧은 형식에서
  벗어납니다" 같은 **경고 문구(룰 템플릿)** 로만 `issues`/`norm_deviations`에 담음.

### 1.4 [P1] 출력 계약(`AI_MODEL_INTERFACE.md §4`) 갱신
- `total_score`: 가중 평균 + clarity 제외로 정의 변경(1.1/1.2).
- 신규 필드: `norm_deviations`, `clarity_warnings`.
- "결정됨 / 구현 예정" 표시로 명확히 구분(현재 동작 서술을 done처럼 덮어쓰지 않음).

## 3. 측정 · 데이터 작업 (구현과 병행)

### 3.1 [P1] 전처리 리사이즈 on/off 성능 측정 → ✅ 결정: **현행 유지(리사이즈 on)** (2026-07-21)
- 오버레이는 **전처리 이미지 기준**으로 확정(좌표 역변환 불필요).
- 측정: `eval/measure_resize.py` — 리사이즈 스텝만 on/off, GT를 off 좌표계로 균일 배율 변환.
  결정 기준(인터뷰): **박스 순증**(이미지별 매칭 박스 손실 없음 + 전체 순증)일 때만 제거.
- **결과** (매칭 박스 on→off, `ImagePreprocessor(apply_resize=False)`):

  | 이미지 | 배율 | m@0.3 on→off | m@0.5 on→off | 지연 on→off |
  |---|---|---|---|---|
  | test.jpg (2216→1280) | 1.73 | 10→**8** | 10→8 | 2.0s→2.0s |
  | test2.png (697→800) | 0.87 | 24→24 | 24→24 | 4.4s→4.5s |
  | test3_crop (변화없음) | 1.00 | 124→124 | 112→112 | 11.0s→10.7s |
  | test6.jpg (4032→1280) | 3.15 | 21→**15** | 21→**12** | 4.3s→**18.6s** |
  | 합계 | | 179→**171** | 167→**156** | |

- **판정**: off가 대형 원본(test.jpg·test6.jpg)에서 박스를 잃고(순증 아님) 지연도 급증 →
  **기각, 현행 리사이즈 유지**. 원인: 리사이즈를 끄면 풀해상도가 CRAFT 내부
  `long_size=960`으로 한 번에 급축소돼 소형 글자 손실. 전처리 1280 선축소(2단계)가 더 안전.
- **부수 산출물**: `ImagePreprocessor.preprocess_*(apply_resize=False)` 토글 추가(기본 True,
  동작 불변) — 향후 재측정·조건부 채택용. 근거가 바뀌면 이 토글로 즉시 재실험 가능.

## 부록: 인터뷰 결정 요약 (2026-07-20)

- 평가 정의: 이미지=자기 일관성+절대 규범 / 캔버스=표준 대비 · 두 모드 동등
- 절대 규범: 대상 자간·기울기·행간, 근거 필기 교본/조판 규범, 자기 일관성과 별도 축
- 기울기 규범 = 수직(0°) 이탈 · 자간 규범 = 띄어쓰기 뭉개짐(자간 분포 이봉성으로 감지)
- 명료도 = 경고만(점수 미반영) · 종합점수 = 지표별 + 가중(정렬·균일 3:2:1)
- 결과 = 점수+등급 병기 · 피드백 = 룰 템플릿, 문서 단위
- 이미지 모드 = 자유 촬영(OCR 없음)
- 캔버스: 표준=명조(기하 기준점) · 획순 복수 정본 · 엔진은 LSTM 교체 목표(위치기반 임시) ·
  기간 내 소규모 LSTM 학습 시도 · 종합점수 현행 감점 유지
- 파인튜닝 = pretrained 확정 후 조건부 재시도 · 평가셋 확장
- 레이턴시 = 실측 기반 하향 · 오버레이 = 전처리 이미지 기준(역변환 불필요)
- 범위 = 대시보드만 유지(개인화·실시간영상·OCR·자유필기 획순은 청사진)
