# 손글씨 AI 평가 지표

## 측정 전제

- 각 글자의 **바운딩 박스(bounding box)** 추출이 기본 단위
- 통계 지표는 주로 **변동계수(CV = σ/μ × 100)** 사용 → 절대값이 아닌 상대적 균일성을 측정

> **2026-07-20 개정 (구현 예정)**: 이미지 모드 평가는 아래 상대 지표(자기 일관성)에 더해
> **절대 규범(별도 축)**과 **가중 종합점수**를 도입합니다. 명료도는 **경고 전용**(점수 미반영)으로
> 바뀝니다. 지표 1~6 정의는 유지되며, 추가 규칙은 문서 끝의 "A. 절대 규범"·"B. 종합점수 및
> 명료도" 절과 `IMPLEMENTATION_PLAN.md`를 참고하세요.

---

## 1. 글자 높이 균일성

- **측정값**: 각 글자 바운딩 박스의 높이(px)
- **지표**: CV (변동계수)
- **기준**
  - CV < 10% → 우수
  - CV 10–20% → 보통
  - CV 20% 이상 → 불량

---

## 2. 기울기 일관성

- **측정값**: 각 글자의 주획(dominant stroke) 기울기 각도(°)
- **지표**: 각도의 표준편차(σ)
- **기준**
  - σ < 3° → 우수
  - σ 3–7° → 보통
  - σ 7° 이상 → 불량

---

## 3. 자간 균등성

- **측정값**: 같은 줄 내 인접 글자 바운딩 박스 사이 거리(px)
- **지표**: CV
- **기준**
  - CV < 15% → 우수
  - CV 15–30% → 보통
  - CV 30% 이상 → 불량
- **구현 각주 (2026-07-19)**: 모서리 간 거리는 붙여 쓴 손글씨에서 평균이 0에
  수렴해 CV가 무의미하게 폭주하므로(실측 test3_crop 151%), 실제 구현은 **인접
  글자 중심 간 거리(pitch)의 CV**를 사용한다. 띄어쓰기 간격(행 높이×0.55 초과)은
  표본에서 제외. 등급 경계는 동일하게 적용.

---

## 4. 행간 균등성

- **측정값**: 줄과 줄 사이 기준선(baseline) 간격(px)
- **지표**: CV
- **기준**
  - CV < 10% → 우수
  - CV 10–20% → 보통
  - CV 20% 이상 → 불량

---

## 5. 기준선 이탈도

- **측정값**: 각 글자 하단 Y좌표 — 해당 줄의 회귀선(fitted baseline) Y값
- **지표**: 이탈 편차 σ ÷ 평균 글자 높이 (정규화)
- **기준**
  - < 5% → 우수
  - 5–15% → 보통
  - 15% 이상 → 불량

---

## 6. 획 굵기 균일성

- **측정값**: 획 위 여러 지점의 폭(px) — distance transform으로 측정
- **지표**: CV
- **기준**
  - CV < 10% → 우수
  - CV 10–25% → 보통
  - CV 25% 이상 → 불량

## A. 절대 규범 (일반 형식 이탈) — 별도 축 (2026-07-20 결정, 구현 예정)

지표 1~6은 "내 글씨끼리 고른가"(자기 일관성)를 봅니다. 하지만 **고르게 썼어도 일반적인 글의
형식을 크게 벗어나면** 안 되므로, 아래 절대 규범을 **자기 일관성 점수와 분리된 별도 축**으로
평가합니다. 점수를 깎지 않고 **경고**로만 제시합니다. 기준값은 **필기 교본/조판 규범**으로
확정 예정(현재는 초안값).

- **기울기 규범 (수직 0° 기준)**: 신뢰 글자 slant의 평균(`mean_angle`) 절대값이 임계(초안
  7~10°)를 넘으면 "글씨가 전체적으로 기울어 곧은 형식에서 벗어남" 경고. 지표 2(일관성 σ)와는
  **별개 축**. (개인 습관 slant를 일정하다고 보고 σ만 보던 기존 전제와 의도적으로 구분.)
- **자간 규범 (띄어쓰기 뭉개짐)**: 한글은 정상적으로도 자간이 좁으므로, 같은 줄 인접 글자
  간격(pitch)의 **이봉 분포**(글자 사이=좁음 / 단어 사이=넓음)에서 넓은 군집이 사라지면
  = 전부 붙여 씀 = "띄어쓰기 뭉개짐" 경고. (기존 자간 지표의 띄어쓰기 제외 로직 `행높이×0.55`
  재활용.) 최소 글자·줄 수 게이트로 오탐 방지.
- **행간 규범 (줄 겹침)**: baseline 간격 절대값 ÷ 평균 글자 높이가 하한(초안 1.0) 미만이면
  "행간이 좁아 줄이 겹침" 경고. 3행 이상만.

## B. 종합점수 및 명료도 (2026-07-20 결정, 구현 예정)

- **명료도(clarity)**: 탐지 이상 글자(과폭/저신뢰/slant 이상치)는 **경고로만** 제시하고
  **종합점수에 반영하지 않음**(모델 탐지 한계를 사용자 필체 탓으로 돌리는 것 방지). 단, 다른
  지표 통계 오염을 막는 **제외 게이트로는 계속 사용**.
- **종합점수**: 지표별 개별 점수를 그대로 노출하고, 아래 **교육적 가중(정렬·균일 우선 3:2:1)**
  으로 가중 평균한 종합점수를 함께 제시. `skipped` 지표는 분자·분모에서 제외. (3:2:1은
  초기값이며 실사용 데이터로 조정.)

  | 지표 | 가중치 |
  |---|---|
  | ① 글자 높이 균일성 | 3 |
  | ⑤ 기준선 이탈도 | 3 |
  | ④ 행간 균등성 | 3 |
  | ② 기울기 일관성 | 2 |
  | ③ 자간 균등성 | 2 |
  | ⑥ 획 굵기 균일성 | 1 |
  | 명료도 | 제외(경고만) |

- **결과 제시**: 각 지표·종합점수 모두 점수(0~100) + 등급(우수/보통/불량) 병기.
